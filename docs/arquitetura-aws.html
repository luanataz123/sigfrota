Como ler

Caixas sólidas = implementado hoje no código: front React em web/ e infra CDK (DynamoDB, Cognito, API Gateway HTTP API com authorizer JWT, Lambda api-lavagens, S3 + CloudFront, SSM, cdk-nag).

Bloco "IA — PLANEJADO" (tracejado/cinza) = specs 5 e 6 (extração de regras e leitura de recibo via Bedrock + Step Functions). Ainda não estão no CDK; o serviço ia-recibo hoje contém apenas fixtures/geradores de recibo.

No MVP de desenvolvimento, o front roda com VITE_USE_MOCK=true (dados mock locais, sem AWS). Com VITE_USE_MOCK=false + VITE_API_BASE_URL, passa a consumir a API real.

Renderizado localmente com Mermaid (CDN). Diagrama fonte: docs/arquitetura-aws.mmd
